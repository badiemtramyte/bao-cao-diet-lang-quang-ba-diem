Kết Nối Google Sheets & Drive

Nhập đường dẫn **Google Apps Script Web App URL** đã triển khai để tự động đẩy dữ liệu Excel lên Sheets và lưu trữ hình ảnh minh chứng vào Google Drive.

Hướng dẫn nhanh:

  1. Tạo 1 file Google Sheet trên tài khoản Admin.
  2. Vào Tiện ích mở rộng -> Apps Script, dán đoạn mã Script xử lý.
  3. Bấm Triển khai -> Triển khai dưới dạng ứng dụng web (Quyền truy cập: "Ai cũng có thể truy cập").
  4. Copy link Web App và dán vào ô ở trên.
Đã lưu báo cáo thành công!
